Design a modern, secure and professional web application UI for a project called "NRI Remote Voting System".

The system allows Non-Resident Indians to vote remotely using Aadhaar verification and biometric fingerprint authentication.

Use a clean government-style interface with colors inspired by the Indian flag (saffron, white, green) with professional typography and card-based layouts.

Create the following screens:

1. ENTRY PAGE (HOME PAGE)
   Display the title "NRI Remote Voting System".
   Provide two large buttons in the center:

* USER LOGIN
* ADMIN LOGIN
  Include a minimal header and footer.

2. ADMIN LOGIN PAGE
   Fields:

* Username
* Password
* Fingerprint Authentication Icon
  Login button.

3. ADMIN DASHBOARD
   After login show three dashboard cards:

* Create User Login
* Registered Users Details
* Election Results

Use icons and a clean dashboard layout.

4. CREATE USER REGISTRATION PAGE
   Design a detailed form containing the following fields:

Personal Information

* Name
* Date of Birth
* Age

Identity Information

* Aadhaar Number
* Voter ID
* Passport Number

Current Residence (Abroad)

* Current Country Name
* Current Address
* Current Pincode
* Current Place

Indian Permanent Address

* Address
* Place
* Pincode

Include a button:
"Capture Fingerprint (Right Thumb)"

Add a Register User button.

5. REGISTERED USERS PAGE
   Display a table containing:

* Name
* Aadhaar Number
* Country
* Constituency
* Voting Status

Include search and filter options.

6. USER LOGIN PAGE
   Field:

* Aadhaar Number

Button:
"Check Registration"

If valid, show:
Fingerprint icon for biometric authentication.

7. USER DASHBOARD PAGE
   Display registered user details in a card layout:

* Name
* Aadhaar
* Passport
* Country
* Indian Address
* Constituency

Below the details add a large button:
"CAST YOUR VOTE"

8. VOTING PAGE
   Display political parties in card format.

Each card must include:

* Party Symbol Image
* Party Name
* Vote Button

Allow selecting only one party.

9. VOTE CONFIRMATION PAGE
   Show selected party with symbol.

Display message:
"Confirm Your Vote"

Two buttons:

* Confirm Vote
* Cancel

10. ELECTION RESULTS PAGE (ADMIN)
    Provide a dropdown to select constituency.

Display:

* Total Registered Voters
* Total Votes Cast

Show party-wise results using bar charts.

Design style requirements:

* Clean government portal design
* Responsive web layout
* Card-based UI
* Clear biometric authentication icon
* Modern UI components
* Consistent spacing and typography
